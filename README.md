# Lingua Bridge — private English ⇄ Spanish translator

A free installable iPhone Home Screen web app starter.

## Features
- Type English and translate to Spanish; swap direction for Spanish to English.
- Speak-to-text using browser speech recognition when supported.
- Keyboard microphone dictation fallback on iPhone.
- Read translations aloud using device speech synthesis.
- Copy translations and keep a short local history.
- No login, no API key, no paid subscription in this starter.

## Important free-service and privacy notes
- Translation uses the public MyMemory endpoint. It is a third-party free service, not an offline model or guaranteed service. Availability, quotas, and terms can change. Text entered for translation is sent to that service.
- Voice recognition availability varies by iOS/Safari version. If the in-page Speak control is unavailable, tap the microphone on the iPhone keyboard to dictate.
- Speech playback uses voices available on the iPhone. Download Spanish and English voices in iOS settings if needed.
- Translation requires an internet connection. The app shell can open offline, but translation cannot.
- Translation quality can vary; check important or high-stakes wording.

## Deploy free with GitHub Pages
1. On your Mac, unzip this package.
2. Create a public GitHub repository named `lingua-bridge`.
3. Upload the files in this folder to the repository root.
4. Open repository Settings → Pages.
5. Choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to provide an HTTPS URL.
7. On your iPhone, open that URL in Safari.
8. Tap Share → Add to Home Screen → Add.
9. Open Lingua Bridge from the new Home Screen icon.

No Apple Developer account or App Store publication is required for this PWA approach.
